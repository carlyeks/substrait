# Substrait Example Plans

This directory contains 81 Substrait logical plan JSON files generated from TPC-H schemas.
Each file is a valid serialized `substrait.Plan` protobuf message and includes a `sql_query`
field showing the equivalent SQL.

The examples were generated by `tools/generate_examples.py` using the `substrait` Python
package (version 0.27.0).

## TPC-H Tables

The examples use the standard TPC-H benchmark schema:

| Table      | Key columns                                              |
|------------|----------------------------------------------------------|
| `lineitem` | orderkey, partkey, suppkey, quantity, extendedprice, discount, tax, returnflag, linestatus |
| `orders`   | orderkey, custkey, orderstatus, totalprice, orderdate     |
| `customer` | custkey, name, address, nationkey, acctbal, mktsegment    |
| `part`     | partkey, name, mfgr, brand, type, size, retailprice       |
| `supplier` | suppkey, name, address, nationkey, acctbal                |
| `partsupp` | partkey, suppkey, availqty, supplycost                    |
| `nation`   | nationkey, name, regionkey                                |
| `region`   | regionkey, name                                           |

## Categories

### Table Scans (8 files)
Simple full-table reads with no predicates.

- `lineitem_scan.json` — `SELECT * FROM lineitem`
- `orders_scan.json` — `SELECT * FROM orders`
- `customer_scan.json` — `SELECT * FROM customer`
- `part_scan.json` — `SELECT * FROM part`
- `supplier_scan.json` — `SELECT * FROM supplier`
- `nation_scan.json` — `SELECT * FROM nation`
- `region_scan.json` — `SELECT * FROM region`
- `partsupp_scan.json` — `SELECT * FROM partsupp`

### Column Projections (3 files)
SELECT with a subset of columns.

- `lineitem_select_key_qty.json` — orderkey, quantity, extendedprice
- `customer_select_name_seg.json` — custkey, name, mktsegment
- `orders_select_key_date.json` — orderkey, orderdate, totalprice

### Filters (16 files)
WHERE clause patterns including simple comparisons, compound predicates, NULL checks,
BETWEEN, LIKE, and three-condition filters.

- `filter_quantity_gt.json` — `WHERE l_quantity > 30`
- `filter_discount_lt.json` — `WHERE l_discount < 0.05`
- `filter_orders_totalprice.json` — `WHERE o_totalprice >= 10000`
- `filter_customer_acctbal_positive.json` — `WHERE c_acctbal > 0`
- `filter_comment_is_null.json` — `WHERE l_comment IS NULL`
- `filter_comment_is_not_null.json` — `WHERE l_comment IS NOT NULL`
- `filter_and_compound.json` — `WHERE l_quantity > 10 AND l_discount < 0.08`
- `filter_or_compound.json` — `WHERE o_orderstatus = 'O' OR o_orderstatus = 'P'`
- `filter_not.json` — `WHERE NOT o_orderstatus = 'F'`
- `filter_quantity_between.json` — `WHERE l_quantity BETWEEN 10 AND 50`
- `filter_name_like.json` — `WHERE c_name LIKE 'Customer%'`
- `filter_name_starts_with.json` — `WHERE c_name LIKE 'Cust%'`
- `filter_three_conditions.json` — discount range AND quantity < 24
- `filter_suppkey.json` — `WHERE ps_suppkey = 42`
- `filter_name_ends_with.json` — `WHERE p_name LIKE '%green'`
- `filter_comment_contains.json` — `WHERE s_comment LIKE '%Customer%'`

### Aggregations (10 files)
COUNT, SUM, AVG, MIN, MAX with optional GROUP BY.

- `agg_count_all.json` — `SELECT COUNT(*) FROM lineitem`
- `agg_sum_qty.json` — `SELECT SUM(l_quantity) FROM lineitem`
- `agg_avg_discount.json` — `SELECT AVG(l_discount) FROM lineitem`
- `agg_min_max_price.json` — MIN and MAX of extendedprice
- `agg_group_by_returnflag.json` — GROUP BY l_returnflag, l_linestatus
- `agg_group_by_orderstatus.json` — GROUP BY o_orderstatus
- `agg_group_by_mktsegment.json` — GROUP BY c_mktsegment
- `agg_group_by_nationkey.json` — GROUP BY c_nationkey
- `agg_count_distinct_approx.json` — `APPROX_COUNT_DISTINCT(o_custkey)`
- `agg_bool_and.json` — `BOOL_AND(l_quantity > 0)` per return flag

### Joins (7 files)
INNER and LEFT joins across TPC-H tables.

- `join_orders_customer_inner.json` — orders ⋈ customer (INNER)
- `join_lineitem_orders_inner.json` — lineitem ⋈ orders (INNER)
- `join_orders_customer_left.json` — orders ⋈ customer (LEFT)
- `join_nation_region.json` — nation ⋈ region (INNER)
- `join_supplier_nation.json` — supplier ⋈ nation (INNER)
- `join_partsupp_part.json` — partsupp ⋈ part (INNER)
- `join_customer_nation.json` — customer ⋈ nation (INNER)

### Sort / ORDER BY (4 files)

- `sort_lineitem_qty_asc.json` — `ORDER BY l_quantity ASC`
- `sort_orders_totalprice_desc.json` — `ORDER BY o_totalprice DESC`
- `sort_customer_acctbal_desc.json` — `ORDER BY c_acctbal DESC`
- `sort_multi_column.json` — `ORDER BY l_returnflag ASC, l_linestatus ASC`

### Fetch / LIMIT-OFFSET (2 files)

- `fetch_top10.json` — `SELECT * FROM orders LIMIT 10`
- `fetch_offset.json` — `SELECT * FROM customer LIMIT 50 OFFSET 100`

### Combinations (8 files)
Multi-operator plans combining filter, project, aggregate, sort, limit, and join.

- `filter_project.json` — filter + select
- `filter_agg.json` — filter + aggregate
- `agg_sort.json` — aggregate + sort
- `filter_agg_sort_limit.json` — filter + aggregate + sort + limit
- `join_filter_select.json` — join + filter + select
- `sort_fetch_combined.json` — sort + limit
- `sort_fetch_lineitem.json` — sort + limit on lineitem
- `filter_project_sort.json` — filter + select + sort

### String Operations (6 files)

- `string_upper.json` — `UPPER(c_name)`
- `string_lower.json` — `LOWER(c_name)`
- `string_length.json` — `CHAR_LENGTH(c_name)`
- `string_concat.json` — `c_name || ' - ' || c_mktsegment`
- `string_substring.json` — `SUBSTRING(c_name, 1, 8)`
- `string_trim.json` — `UPPER(c_name), LOWER(c_mktsegment)`

### Arithmetic / Math (6 files)

- `arith_multiply.json` — `l_extendedprice * (1 - l_discount)`
- `arith_revenue_with_tax.json` — `l_extendedprice * (1 - l_discount) * (1 + l_tax)`
- `arith_abs.json` — `ABS(c_acctbal)`
- `arith_negate.json` — `-c_acctbal`
- `round_ceil_floor.json` — `CEIL(l_discount), FLOOR(l_discount)`
- `sqrt_power.json` — `SQRT(l_quantity), POWER(l_quantity, 2)`

### Computed Projections (3 files)

- `project_computed.json` — computed net price column
- `project_string_ops.json` — upper + char_length
- `project_coalesce.json` — `COALESCE(c_comment, 'N/A')`

### Miscellaneous (3 files)

- `singular_or_list.json` — IN ('O', 'P', 'F') predicate
- `cross_join.json` — `region CROSS JOIN nation`
- `if_then.json` — CASE WHEN expression

### TPC-H Inspired Queries (5 files)

- `tpch_q1_pricing_summary.json` — Pricing Summary Report
- `tpch_q3_shipping.json` — Shipping Priority Query (simplified)
- `tpch_q5_local_supplier.json` — Local Supplier Volume (simplified)
- `tpch_q6_revenue.json` — Forecasting Revenue Change
- `tpch_q10_returned.json` — Returned Item Reporting (simplified)
